## 🛠️ Core Competencies

- **Engenharia de Dados & SQL:** Consultas analíticas avançadas, Window Functions, modelagem Dimensional (Star Schema, Snowflake) e otimização de queries em PostgreSQL, MySQL e BigQuery.
- **Python para Análise:** Manipulação e processamento com `pandas`, `numpy`, visualização com `matplotlib`, `seaborn` e automação com scripts agendados.
- **Business Intelligence & Dashboards:** Criação de relatórios executivos no Microsoft Power BI com modelagem DAX complexa, governança de dados e métricas em tempo real.
- **Data Storytelling & Tradução de Negócios:** Transformação de dados brutos em decisões estratégicas de receita, redução de custos e mitigação de churn.

---

## 🏛️ Web Architecture

- **Zero-Dependency Core:** HTML5 semântico estruturado para SEO e acessibilidade (a11y).
- **Design System Modular:** Variáveis CSS nativas, tema Dark Slate com contraste calibrado e tipografia profissional.
- **Hardware-Accelerated Transitions:** Animações CSS com aceleração GPU (`transform: translate3d`) garantindo 60 FPS estáveis.

## 💻 Local Development

Inicie o servidor estático localmente:

```bash
# Clone o repositório
git clone https://github.com/ManoAlee/giovanni-savassa-portfolio.git
cd giovanni-savassa-portfolio

# Inicie o servidor via PowerShell
.\server.ps1

# Ou utilizando Python
python -m http.server 8080
```
